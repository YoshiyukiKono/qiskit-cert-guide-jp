# 14_phase.md

# Part 14：位相ゲート（Z / S / T）と phase kickback を完全に理解する

これまで学んできた：

* Hゲート
* Xゲート
* CNOT
* measurement

は主に：

```text
振幅
```

を扱っていました。

ここからは：

```text
位相（phase）
```

を扱います。

ここが量子計算の本質です ⭐

---

# 1. 位相とは何か

状態：

|\psi\rangle=a|0\rangle+b|1\rangle

ここで：

* a は振幅
* b は振幅

ですが、

```text
振幅は複素数
```

です。

つまり：

```text
大きさ + 角度
```

を持っています。

この角度が：

```text
phase
```

です。

---

# 2. Zゲートとは何か

Zゲート：

Z|0\rangle=|0\rangle

Z|1\rangle=-|1\rangle

つまり：

```text
|1⟩ にマイナス符号を付ける
```

だけです。

---

# 3. QiskitでのZゲート

例：

```python
qc.z(0)
```

意味：

```text
位相反転
```

です。

---

# 4. Zゲートは確率を変えない

状態：

[
(|0⟩+|1⟩)/\sqrt{2}
]

にZをかけると：

[
(|0⟩-|1⟩)/\sqrt{2}
]

になります。

しかし：

```text
測定確率は同じ
```

です。

なぜなら：

```text
符号は確率に影響しない
```

からです。

---

# 5. ではなぜ位相が重要なのか？🤔

理由：

```text
干渉を変える
```

からです。

例：

H → Z → H

を考えます。

---

# 6. HZHの計算

重要関係：

HZH=X

つまり：

```text
位相操作がビット反転になる
```

のです。

これは試験頻出です。

---

# 7. Sゲートとは何か

Sゲート：

S|0\rangle=|0\rangle

S|1\rangle=i|1\rangle

つまり：

```text
90度回転
```

です。

---

# 8. Tゲートとは何か

Tゲート：

T|1\rangle=e^{i\pi/4}|1\rangle

つまり：

```text
45度回転
```

です。

---

# 9. 位相回転のまとめ

| ゲート | 回転角  |
| --- | ---- |
| Z   | 180° |
| S   | 90°  |
| T   | 45°  |

つまり：

```text
Z = S²
```

かつ：

```text
S = T²
```

です。

---

# 10. なぜTゲートが重要なのか ⭐

理由：

```text
Clifford + T = universal
```

だからです。

つまり：

```text
Tがあれば任意の量子回路が作れる
```

試験でも重要概念です。

---

# 11. 位相ゲートはBloch球で何をしているか

X：

```text
左右回転
```

Z：

```text
上下回転
```

つまり：

```text
回転軸が違う
```

だけです。

---

# 12. phase kickbackとは何か

最重要概念のひとつです ⭐⭐⭐

回路：

```
control ──■──
          │
target ──Z──
```

結果：

```text
control に位相が戻る
```

これが：

```text
phase kickback
```

です。

---

# 13. phase kickbackの数式

例：

状態：

[
|+\rangle|1\rangle
]

にCZを作用：

結果：

[
(|0\rangle-|1\rangle)/\sqrt{2}
]

つまり：

```text
targetではなく control に位相が出現
```

します。

---

# 14. なぜこれが重要なのか 🚀

理由：

量子アルゴリズムでは：

```text
関数値を位相として書き込む
```

からです。

例：

* Grover
* QFT
* Phase estimation
* Shor

すべてここに依存します。

---

# 15. CZゲートとは何か

CZ：

CZ|11\rangle=-|11\rangle

それ以外：

```text
変化なし
```

---

# 16. CZとCNOTの関係

重要：

CZ=(I\otimes H),CX,(I\otimes H)

つまり：

```text
基底変換で相互変換可能
```

です。

試験でよく出ます。

---

# 17. 位相が干渉を変える例

回路：

```
H → Z → H
```

結果：

```text
X
```

回路：

```
H → I → H
```

結果：

```text
I
```

つまり：

```text
Zの有無だけで結果が変わる
```

これが：

```text
干渉制御
```

です。
