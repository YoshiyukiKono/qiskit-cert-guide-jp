# 06_bloch.md

# Part 6：Bloch球（Bloch sphere）を完全に理解する

Bloch球とは：

```text
量子状態を球面上の点として表す方法
```

です。

単一量子ビットはすべて：

```text
Bloch球の表面のどこか
```

に対応します。

---

# 1. Bloch球とは何か

量子状態：

[
|\psi\rangle=a|0\rangle+b|1\rangle
]

は次の形で書き直せます：

\lvert\psi\rangle=\cos\frac{\theta}{2}\lvert0\rangle+e^{i\phi}\sin\frac{\theta}{2}\lvert1\rangle

ここで：

| 記号 | 意味      |
| -- | ------- |
| θ  | 緯度（回転角） |
| φ  | 経度（位相角） |

つまり：

```text
量子状態＝球面座標
```

として表せます。

---

# 2. 北極と南極

Bloch球の基本位置：

| 状態 | 位置 |    |
| -- | -- | -- |
|    | 0⟩ | 北極 |
|    | 1⟩ | 南極 |

つまり：

```text
古典ビットは球の上下
```

に対応します。

---

# 3. 赤道（superposition状態）

例：

[
(|0\rangle+|1\rangle)/\sqrt{2}
]

これは：

```text
赤道上
```

に位置します。

つまり：

```text
最大の重ね合わせ
```

です。

---

# 4. 位相φの意味

状態：

[
(|0\rangle+|1\rangle)/\sqrt{2}
]

と

[
(|0\rangle-|1\rangle)/\sqrt{2}
]

は：

```text
同じ赤道
```

ですが：

```text
経度が違う
```

つまり：

```text
φが違う
```

ということです。

---

# 5. なぜθ/2なのか

式に：

```text
θ/2
```

が出てきます。

理由：

Bloch球は：

```text
状態ベクトルの2倍の角度
```

で回転するからです。

これは量子力学の基本性質です。

資格試験では：

```text
理解していればOK
```

レベルです。

---

# 6. Hadamardはどこへ動かすか

Hadamard：

[
|0\rangle \rightarrow (|0\rangle+|1\rangle)/\sqrt{2}
]

つまり：

```text
北極 → 赤道
```

への移動です。

---

# 7. Zゲートの動き

Zゲートは：

```text
z軸回転
```

です。

つまり：

```text
北極は動かない
```

しかし：

```text
赤道上の点は回転する
```

---

# 8. Xゲートの動き

Xゲート：

```text
x軸回転
```

つまり：

```text
北極 ↔ 南極
```

を入れ替えます。

---

# 9. Yゲートの動き

Yゲート：

```text
y軸回転
```

です。

つまり：

```text
xとzの中間回転
```

になります。

---

# 10. Pauliゲート＝180度回転

重要：

| ゲート | 回転     |
| --- | ------ |
| X   | x軸180° |
| Y   | y軸180° |
| Z   | z軸180° |

つまり：

```text
Pauliゲート＝半回転
```

です。

---

]

```text
x軸方向にθ回転
```

```python
qc.rx(theta, 0)
```

# 13. 回転ゲート Rz

定義：

[

]

意味：

```text
z軸方向にθ回転
```

例：


# 14. 回転ゲートと位相の関係

重要：

```text
Rz = 位相回転
```

つまり：

| ゲート | 等価      |
| --- | ------- |
| Z   | Rz(π)   |
| S   | Rz(π/2) |
| T   | Rz(π/4) |

資格試験頻出です。

# 15. Qiskitで回転を見る

例：

```python
from qiskit import QuantumCircuit
from qiskit.quantum_info import Statevector
import numpy as np

qc = QuantumCircuit(1)

qc.ry(np.pi/2, 0)

state = Statevector.from_instruction(qc)

print(state)
```

結果：

```text
赤道へ移動
```
