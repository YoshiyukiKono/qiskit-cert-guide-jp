# Part 1：量子ビット（qubit）を完全に理解する

この章では、量子コンピューティングの最小単位である **量子ビット（qubit）** を理解します。

ここは資格試験の**最重要領域**です。

試験では：

* 状態ベクトルが読めるか
* 確率振幅が理解できるか
* 正規化条件が分かるか

が問われます。

---

# 1. 古典ビットとの違い

まず比較から始めます。

古典ビット：

```
0 または 1
```

量子ビット：

```
0 と 1 の重ね合わせ
```

つまり：

```
同時に両方になれる
```

ただし注意：

これは「半分0で半分1」という意味ではありません。

---

# 2. 量子ビットの数学的表現

量子ビットは次の形で表されます：

$$
\lvert \psi \rangle = a\lvert 0 \rangle + b\lvert 1 \rangle
$$

ここで：

| 記号 | 意味     |
| -- | ------ |
| ψ  | 状態     |
| a  | 0になる振幅 |
| b  | 1になる振幅 |

重要：

a と b は **確率そのものではありません**

---

# 3. 確率振幅とは何か

観測結果の確率は：

```
|a|²
|b|²
```

で決まります。

例：

```
a = 1
b = 0
```

なら：

```
100% |0⟩
```

例：

```
a = 1/√2
b = 1/√2
```

なら：

```
50% |0⟩
50% |1⟩
```

---

# 4. 正規化条件（試験頻出）

量子状態には必ず次の制約があります：

```
|a|² + |b|² = 1
```

これを：

**正規化条件**

と呼びます。

例：

これはOK：

```
a = 0.6
b = 0.8
```

なぜなら：

```
0.36 + 0.64 = 1
```

これはNG：

```
a = 0.7
b = 0.7
```

なぜなら：

```
0.49 + 0.49 ≠ 1
```

---

# 5. なぜ確率ではなく振幅なのか

ここが量子計算の本質です。

古典確率：

```
直接足す
```

量子確率：

```
振幅を足してから2乗する
```

つまり：

```
干渉が起きる
```

これが量子高速化の源です。

---

# 6. 基底状態（basis states）

基本状態は2つだけです：

```
|0⟩
|1⟩
```

ベクトルとして表すと：

```
|0⟩ = [1, 0]
|1⟩ = [0, 1]
```

この2つの組み合わせがすべての量子状態になります。

---

# 7. Qiskitで状態を確認する

Statevectorを使います。

```python
from qiskit import QuantumCircuit
from qiskit.quantum_info import Statevector

qc = QuantumCircuit(1)

state = Statevector.from_instruction(qc)

print(state)
```

出力：

```
[1.+0.j 0.+0.j]
```

意味：

```
|0⟩
```

---

# 8. Hadamardで重ね合わせを作る

次：

```python
qc = QuantumCircuit(1)

qc.h(0)

state = Statevector.from_instruction(qc)

print(state)
```

出力：

```
[0.707+0.j 0.707+0.j]
```

意味：

```
1/√2 |0⟩ + 1/√2 |1⟩
```

---

# 9. 確率を計算する

確率は：

```
振幅²
```

つまり：

```
0.707² = 0.5
```

したがって：

| 状態 | 確率 |     |
| -- | -- | --- |
|    | 0⟩ | 50% |
|    | 1⟩ | 50% |

---

# 10. 測定とは何か

測定すると：

```
状態が壊れる
```

例：

```
1/√2(|0⟩ + |1⟩)
```

を測定すると：

```
|0⟩ または |1⟩
```

どちらかになる。

そして：

元には戻らない。

---

# 11. よくある試験問題

問題：

次の状態の測定確率は？

```
|ψ⟩ = 0.6|0⟩ + 0.8|1⟩
```

解答：

```
|0⟩ → 0.36
|1⟩ → 0.64
```

---

問題：

次は量子状態として正しいか？

```
0.5|0⟩ + 0.5|1⟩
```

答え：

NG

理由：

```
0.25 + 0.25 ≠ 1
```

---

# 12. Statevectorの読み方（試験重要）

例：

```
[0.6+0.j 0.8+0.j]
```

意味：

```
0.6|0⟩ + 0.8|1⟩
```

確率：

```
36%
64%
```

---

# 13. 複素数が出てきた場合

例：

```
[0.707+0.j 0+0.707j]
```

確率：

```
0.5
0.5
```

なぜなら：

```
|0.707j|² = 0.5
```

位相は違っても確率は同じです。
