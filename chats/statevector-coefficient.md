はい。ここは **「配列の各要素は何を表しているのか」** と **「Statevector はベクトルなので、全体の長さが1でなければならない」** の2点を分けると、一気に分かりやすくなります。

たとえば

```python
sv0011 = Statevector(np.array([1, 0, 0, 1]))
```

は、2量子ビットなので、配列の4成分は順番に

$$
|00\rangle,\ |01\rangle,\ |10\rangle,\ |11\rangle
$$

の**係数（amplitude）**です。つまり、この配列をそのまま数式にすると、

$$
1|00\rangle
+0|01\rangle
+0|10\rangle
+1|11\rangle
$$

なので、

$$
|00\rangle+|11\rangle
$$

です。

ここまでは、「1が一つ」の場合と同じ考え方です。たとえば

```python
Statevector([1, 0, 0, 0])
```

なら

$$
1|00\rangle=|00\rangle
$$

です。

ただし、`[1, 0, 0, 1]` にはもう一つ問題があります。

### 「1が二つある」＝2つの状態が候補、ではあるが、確率ではない

Statevector の成分は**確率そのものではなく振幅**です。測定確率は振幅の絶対値の二乗です。

もし本当に

$$
\begin{pmatrix}
1\\
0\\
0\\
1
\end{pmatrix}
$$

なら、

$$
|00\rangle
$$

の確率は

$$
|1|^2=1
$$

で、

$$
|11\rangle
$$

の確率も

$$
|1|^2=1
$$

になってしまいます。

合計すると

$$
1+1=2
$$

です。

でも、測定結果の確率の合計は必ず

$$
1
$$

でなければなりません。

したがって、量子状態として使うには**規格化（normalization）**して、

$$
\frac{1}{\sqrt2}
\begin{pmatrix}
1\\
0\\
0\\
1
\end{pmatrix}
$$

とします。

つまり

```python
sv = Statevector(
    np.array([1, 0, 0, 1]) / np.sqrt(2)
)
```

です。

これは

$$
\frac{1}{\sqrt2}|00\rangle
+
\frac{1}{\sqrt2}|11\rangle
$$

を表します。

そして測定すると、

$$
P(00)
=
\left|\frac1{\sqrt2}\right|^2
=
\frac12
$$

$$
P(11)
=
\left|\frac1{\sqrt2}\right|^2
=
\frac12
$$

となります。

---

特に覚えやすいのは、次の対応です。

| Statevector               | 状態               |            |             |
| ------------------------- | ---------------- | ---------- | ----------- |
| `[1,0,0,0]`               | $                | 00\rangle$ |             |
| `[0,1,0,0]`               | $                | 01\rangle$ |             |
| `[0,0,1,0]`               | $                | 10\rangle$ |             |
| `[0,0,0,1]`               | $                | 11\rangle$ |             |
| $\frac1{\sqrt2}[1,0,0,1]$ | $\frac1{\sqrt2}( | 00\rangle+ | 11\rangle)$ |

なので、**「1の位置を見る」**という最初の直観はそのまま使えます。

ただし、

> 1が一つ → その基底状態そのもの
> 1が複数 → 複数の基底状態を足したもの。ただし全体を規格化する必要がある

と一段だけ拡張するとよいです。

さらに重要なのは、たとえば

$$
\frac1{\sqrt2}[1,0,0,-1]
$$

も、測定確率だけ見れば同じく $00$ が50%、$11$ が50%ですが、これは

$$
\frac{|00\rangle-|11\rangle}{\sqrt2}
$$

で、`+1` と `-1` の違い、つまり**相対位相**を持つ別の量子状態です。

このため最終的には、Statevector の配列を

> **「各マスが各基底状態に対応し、そこに書かれている数がその基底状態の振幅」**

と考えるのが一番うまくいきます。

```text
        |00>  |01>  |10>  |11>
          ↓     ↓     ↓     ↓
       [ 1/√2,  0,    0,   1/√2 ]
```

これはかなり大事な見方で、この感覚がつかめると、`[a,b,c,d]` を見て

$$
a|00\rangle+b|01\rangle+c|10\rangle+d|11\rangle
$$

と読むことが自然になってきます。
