# ゲートの合成と基底変換への再構成

検証日: 2026-09-14 JST

## 対象と説明の設計

[第1章の対象節](../ja/01-quantum-operations.md#matrix-order)を「行列と演算順序」から「ゲートの合成と基底変換」へ改題した。[編集方針](../editorial-policy.md)に、一般的な概念の中に代表例を位置付け、導出後に別の例や応用へ戻る方針を追加した。

- 導入の学習目標を、個別のHZH=Xから、ゲートの合成・共役変換・測定基底の変更へ広げた。
- 基底、逆操作、ユニタリ行列、複素共役転置を説明し、共役変換の一般形と状態への作用を示した。
- HZH=Xの既存の導出は、入力0、入力1、任意の重ね合わせ、行列積、コードと出力を含めて維持した。
- HとSによるPauli演算子の変換を比較した。SXS†は途中の行列積を示し、逆操作と順序が必要な理由を説明した。
- X・Y基底から計算基底へ戻して測る手順を、基底状態の対応、観測量の共役変換、複素振幅を含む実行例の三つで説明した。
- 条件を変えた小問を2問追加し、SとS†の取り違えやY測定前の操作順の誤りを確かめられるようにした。

旧来の明示アンカー`matrix-order`を維持し、旧見出し由来の`行列と演算順序`も明示アンカーとして残した。coverageと編集記録の参照名を更新した。本文にはMock名、問題番号、問題・解答へのリンクを追加していない。

## 再実行

Python 3.12.14、Qiskit 2.5.2、qiskit-ibm-runtime 0.49.0、NumPy 2.5.3の一時仮想環境を使用した。リポジトリのルートから次を実行する。

```text
python manuscript/validation/verify_sample_sections.py
```

[検証スクリプト](verify_sample_sections.py)は、原稿からPythonコードと掲載出力を直接抽出する。今回の対象節は独立実行する2例となり、既存の期待値節と第6章を含め、合計13例を検証する。QPUへの送信は行わない。

## 検証内容

| 対象 | 照合方法 |
|---|---|
| Hによる共役変換 | HZH、HXHに加え、HYHの符号を行列で確認。Hの係数を外した整数・複素数の演算でも照合 |
| Sによる共役変換 | X→Y、Y→−X、Z→Zをそれぞれ行列で照合 |
| 一般形の向き | 逆操作が自身と異なるユニタリ行列で、演算子を移す共役変換と、新しい基底での行列表現をそれぞれ確認 |
| 一般化の限界 | TによるXの変換が単独のPauli演算子にはならない例も確認 |
| 測定前のゲート列 | 掲載コードの回路から行列を取得し、H、HS†の順序と、対応する観測量X・Yを照合 |
| 測定確率 | 0・1・±・±iと、複素振幅が等しくない状態について、X・Y固有基底への直接射影と、回路による基底変換後の確率を比較 |
| 数値例の手計算 | Xの確率1/2ずつ、Yの確率(2±√3)/4を掲載コードと照合 |
| 小問の反例 | SXSとYが一方の基底状態だけで一致すること、Y測定前の順序を逆転すると確率が変わることを確認 |

導出の保存と対象節外の本文の一致は、作業開始時の原稿との比較で確認した。Markdown/KaTeXによる第1章・第6章の数式変換、既存リンクの到達先、旧見出しのアンカーも確認した。
