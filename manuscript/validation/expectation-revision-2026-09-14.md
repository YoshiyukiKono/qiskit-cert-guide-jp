## 対象と変更内容

[編集方針](../editorial-policy.md)に従い、[第1章のobservableと期待値](../ja/01-quantum-operations.md#expectation)を改稿した。最初の見本2節で確認した説明の詳しさを引き継ぎ、特定のMockへの言及・リンクを本文に置かない。

- 記録するbitと観測量の測定値を区別し、確率による重み付き平均から期待値を導入した。
- 固有値・固有状態・エルミート行列を説明し、確定する測定値と対応させた。
- bra、複素共役、正規化を説明してから、行列による期待値の途中計算を示した。
- 同じ状態に対するXとZの違い、複数量子ビットの積の測定値、観測量の和を順に扱った。
- 単独で実行できるコード例2件と出力、有限標本による推定、理由付き確認問題4問を加えた。

第1章の他の節や章末チェックは維持した。前回までの改稿はそのまま残し、全章への展開は今回も行っていない。

最初の見本改稿と同じ一時仮想環境（Python 3.12.14 / Qiskit 2.5.2 / NumPy 2.5.3）を使用した。Runtime/QPU実行は含めない。これは期待値節の改稿時点の記録である。後続の第6章改稿でスクリプトに検証項目を追加しており、現在の再実行にはqiskit-ibm-runtime 0.49.0も必要となる。最新の範囲は[基底変換の改稿記録](conjugation-revision-2026-09-14.md)を参照する。

```bash
python manuscript/validation/verify_sample_sections.py
git diff --check
```

[検証スクリプト](verify_sample_sections.py)を拡張し、原稿からコードと掲載出力を抽出する対象に期待値節を追加した。この時点の検証は、前の2節を含む計3節・5コードブロックを対象とした。
